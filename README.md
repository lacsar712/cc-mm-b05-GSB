# 矿井瓦斯班测台

检查员上报测点甲烷浓度。达到 1% 时，服务端通过网页套接字把这条报警推到已经打开的页面。页面是手写脚本，没有用组件框架，也没有图表。

检查员可以把报警线**临时抬高**到 1% 以上并设定失效时刻：失效前新上报按临时线判定、按临时线推送；失效后自动回到百分之一。每次抬高只追加写入履历，旧临时线与失效时刻不会被后续抬高覆盖。旁观账号只能看（含只读履历），不能抬高也不能上报。

## 验收

1. 用 gasman 登录，列表里回风巷是报警，东翼-12 是正常。
2. 再开一个浏览器窗口同时看列表，上报一个大于等于 1 的测点，两个窗口都会出现新记录。
3. viewer 登录后没有上报表单，也没有抬高报警线表单。

### 临时抬高报警线

1. gasman 登录，把临时线抬到 **1.5**、失效秒数填 **3**，履历立刻出现一条 1.5 的记录，当前报警线显示“临时 1.5%”。
2. 失效前上报一个 **1.2** 的测点：判为**正常**、不推送报警（说明里写明按临时线 1.5% 判定）。
3. 同一窗口再上报 **1.6**：判为报警并立即推送——推送规则跟着新线走。
4. 再抬高一次（如 1.3）：履历追加为两条，原来 1.5 的临时线与失效时刻保持不变。
5. 用 viewer 登录可以查看履历，但调用抬线接口返回 403。
6. 等临时线失效后，当前报警线自动回到 **1%**，履历中的记录标记“已失效”但仍保留；此时再上报 **1.2**，判为**报警**并推送。

### 接口

| 方法 | 路径 | 权限 | 说明 |
|------|------|------|------|
| POST | `/api/thresholds` | 检查员 | 抬高临时线，体例如 `{"threshold_pct": 1.5, "expires_in_seconds": 3}`，也支持绝对失效时刻 `expires_at`（ISO-8601）。线值必须高于 1%，失效时刻必须在未来。 |
| GET | `/api/thresholds/current` | 已登录 | 当前生效线；无生效临时线时返回 1%。 |
| GET | `/api/thresholds/history` | 已登录 | 临时线履历（只读），含每条的失效时刻、设定人、生效中/已失效状态。 |

判定与推送以**上报时刻**最新一条未失效履历为准：`ch4 >= 当前线` 判报警，只有报警才经 `/ws/alerts` 推送。
