# 矿井瓦斯班测台

检查员上报测点甲烷浓度。达到报警线（默认 1%）时，服务端通过网页套接字把这条报警推到已经打开的页面；低于当前线的正常读数不推送。页面是手写脚本，没有用组件框架，也没有图表。

## 临时抬高报警线

检查员可以把报警线临时抬高（必须高于 1%），并设定失效时刻（最长 24 小时）：

- 失效前，新上报按临时线判定，推送规则跟着新线走（低于临时线不推送报警）。
- 失效后自动回到 1%，不需要人工复位。
- 每次抬高追加一条履历（临时线、设定时刻、失效时刻、设定人），旧履历不被后续抬高覆盖。
- 旁观账号只能读当前线和履历，不能抬线。

接口：

| 方法 | 路径 | 说明 |
|------|------|------|
| GET | /api/thresholds | 当前线、生效中的临时线、完整履历（登录即可读） |
| POST | /api/thresholds | 抬线，body：`{"threshold": 1.5, "valid_seconds": 120}`（仅检查员） |

## 验收

1. 用 gasman 登录，列表里回风巷是报警，东翼-12 是正常。
2. 再开一个浏览器窗口同时看列表，上报一个大于等于当前线的测点，两个窗口都会出现新记录。
3. viewer 登录后没有上报表单，也没有抬线表单，只能看履历。
4. 临时抬线：gasman 把线抬到 1.5 并设较短失效（如 120 秒）。报 1.2 判正常、不推送报警，履历里留下 1.5 那条。等失效后当前线自动回到 1%，再报 1.2 判报警并推送。
